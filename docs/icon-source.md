# Govee Mac icon

The approved icon is a sculpted white standing lamp on a dark rounded tile, generated with the built-in ImageGen tool on October 8, 2026. The final prompt is in [icon-prompt.txt](icon-prompt.txt). No Govee trademark or upstream app artwork is included.

`docs/icon.png` is the source artwork. `Resources/GoveeMac.icns` is the packaged macOS icon. Run `swift script/make_icon.swift` to regenerate the iconset from the approved PNG without changing the artwork.
